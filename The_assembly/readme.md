# Banco de Pruebas Científico MOSFET

Simulador educativo en Python para explorar transistores MOSFET, visualizar gráficas eléctricas y experimentar con modelos térmicos y redes neuronales.

## Instalación con Bash

```bash
python -m pip install --upgrade pip
python -m pip install numpy pygame tensorflow
pip install pyserial
```

## Ejecutar

```bash
python main.py
```

## Dependencias

- `numpy`: cálculos numéricos.
- `pygame`: interfaz gráfica.
- `tensorflow`: red neuronal experimental.
- Con pyserial conecta tu arduino!Ves con cuidado!no testeado!

**Nota:** Proyecto educativo y experimental. Los resultados requieren validación independiente para confirmar su precisión física.
