# Teorema de la Resonancia Radio Espacial

Hola. Soy **Nadal Ferrá**, investigador independiente. Este repositorio presenta la formulación de mi **Teorema de la Resonancia Radio Espacial**, desarrollado para la localización precisa de fuentes de radio cósmicas (como los FRB).

## ¿De qué trata este trabajo?
En lugar de dar por sentado que los métodos habituales de localización funcionan, este teorema **demuestra matemáticamente bajo qué condiciones convergen**, ofreciendo una cota explícita del error y una tasa de convergencia probada en función de las observaciones y del medio intergaláctico.

## Puntos Destacados
* **Cota de error explícita:** Una fórmula directa que vincula el error de localización con la geometría de los detectores, el ruido temporal y la distancia a la fuente.
* **Guía de diseño:** Permite calcular de manera exacta cuántos detectores se necesitan para alcanzar una precisión espacial determinada.
* **Falsabilidad:** El modelo es estrictamente refutable mediante observaciones reales.
* **Contraste con datos reales:** Al aplicarlo con parámetros del radiotelescopio CHIME, la cota teórica predice una precisión de orden de 10 pársecs, perfectamente alineada con los datos interferométricos actuales.

## Documentación
El documento completo (`propuesta_tecnica_frb.pdf`) detalla las hipótesis físicas del medio, la demostración paso a paso basada en estadística asintótica, la tabla de valores de CHIME y las limitaciones actuales del modelo (como turbulencias o ruido con colas pesadas).
