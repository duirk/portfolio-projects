
# 🚀 NASA / TORCHI SYSTEM -  QUANTUM INTERFACE

Un simulador de interfaz aeroespacial  desarrollado en Python utilizando **Pygame**, diseñado para emular a la perfección 
las consolas de computación de misiones espaciales clásicas con monitores CRT de fósforo verde.
BASE EXPERIMENTAL
---

## 🖥️ Características Principales

* **Estética CRT Auténtica:** Interfaz visual inmersiva con paleta de colores de fósforo verde y cian,
*  líneas de contorno y tipografías de consola estilo terminal clásica.
* **Algoritmo 1 (Distancias y Medidas):** Simulación en tiempo real de variables físicas,
* MET (Mission Elapsed Time), cálculo de péndulo en vivo y constantes cuánticas (como la constante de Planck: $6.626e-34$ J·s).
* **Algoritmo 2 (Sistema 3x3 y Afín):** Gestión matricial avanzada con cálculo
* dinámico del operador diferencial temporal (d/dt), integrales y morfismo de espacio-afín (traza tensorial).
* **Homeomorfismo y Ondas:** Trazado en tiempo real de ondas senoidales combinadas y esferones animados en el espacio de trabajo.
* **Interactividad en Vivo:**
* Presiona **'R'** para generar y reiniciar matrices aleatorias de forma instantánea.
* Presiona **'E'** para introducir y configurar una matriz 3x3 personalizada directamente desde la consola.

## 🛠️ Requisitos e Instalación

1. Asegúrate de tener Python instalado en tu sistema.
2. Instala la librería requerida ejecutando el siguiente comando en tu terminal:
```bash
pip install pygame
pip install pyinstaller

```



## 🚀 Ejecución

Clona o descarga el archivo principal del script (por ejemplo, `cosmos3.py`) y ejecútalo con:

```bash
python cosmos3.py
pyinstaller --onefile --noconsole cosmos3.py
```
