# Modelo de Conectividad 
(filosófia matemática.)
Este proyecto explora la idea teórica de una conexión entre la actividad del cerebro humano y las dinámicas del espacio exterior. 

El proyecto propone un marco abstracto que utiliza geometría, mapas de energía y variaciones temporales para analizar cómo la mente y el universo podrían interactuar o compartir patrones de comportamiento similares.
