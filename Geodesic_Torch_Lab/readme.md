# IGNIS-PATH: Teletransportación de Datos Numéricos

**Autor:** Nadal Ferrá | **Fecha:** 21/10/2026 | **Investigador Independiente**  

## Resumen del Proyecto

Soy Nadal Ferrá, investigador independiente. Presento **IGNIS-PATH (EPIC-GD)**, un proyecto enfocado en la **teletransportación de datos numéricos** dentro de espacios de parámetros complejos.

En lugar de avanzar paso a paso como los optimizadores tradicionales, Geodesic_Torch_Lab aprovecha la geometría del espacio para realizar saltos geodésicos directos hacia la solución.

## Puntos Clave

* **Salto Instantáneo:** Resolvemos problemas numéricos masivos en un solo paso mediante el colapso por simetría.
* **Dinámica Adaptativa:** Guíamos los datos evitando barreras locales sin pérdida de información.
* **Módulos:** Incluye la implementación del algoritmo en PyTorch (`ignis_path.py`) para pruebas y desarrollo.
